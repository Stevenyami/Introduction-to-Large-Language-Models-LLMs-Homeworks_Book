# Introduction to Large Language Models (LLMs) - Homework Exercises Book

A comprehensive collection of homework exercises from the course **Introduction to Large Language Models (LLMs)**. This repository contains structured exercises covering fundamental to advanced concepts in machine learning, deep learning, and large language models.

## 📚 Course Topics Covered

This collection includes exercises on:

- **Machine Learning**: Foundational ML concepts, algorithms, and techniques
- **Deep Learning**: Neural network architectures and deep learning fundamentals
- **Neural Networks**: Network structures, activation functions, and architectures
- **LLM Architectures**: Transformer models, attention mechanisms, and modern LLM designs
- **Word and Sentence Embeddings/Disambiguation**: Vector representations and semantic understanding
- **Parsing**: Syntactic analysis and language structure
- **Hyperparameters Tuning**: Model optimization and parameter selection
- **Optimization Functions**: Loss functions, gradient descent, and optimization algorithms
- **Training & Fine-Tuning Procedures**: Model training strategies and transfer learning
- **Metrics & Evaluation Protocol**: Performance measurement and model evaluation

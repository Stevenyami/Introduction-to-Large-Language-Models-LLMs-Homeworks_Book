# Word and Sentence Embeddings / Disambiguation

## Overview

This section covers vector representations of words and sentences, semantic understanding, and disambiguation techniques essential for NLP tasks.

## Learning Objectives

- Understand word embedding techniques
- Master sentence and document embeddings
- Learn contextualized representations
- Implement disambiguation strategies
- Work with pre-trained embeddings
- Analyze semantic relationships

## Topics Covered

1. **Word Embeddings**: Word2Vec, GloVe, FastText
2. **Sentence Embeddings**: Averaging, learned representations
3. **Contextualized Embeddings**: ELMo, BERT embeddings
4. **Word Sense Disambiguation**: Context-based disambiguation
5. **Semantic Similarity**: Cosine similarity, distance metrics
6. **Embedding Analysis**: Analogies, bias detection

## Prerequisites

- Neural Networks basics
- NLP fundamentals
- Linear Algebra
- Python and NumPy

## Recommended Tools

- Gensim (Word2Vec)
- Sentence Transformers
- NLTK/spaCy
- Hugging Face Transformers

Theory and implementation with real-world applications
